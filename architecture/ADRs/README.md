## Architectural Decision Records (ADRs)

Use ADRs to document significant technical and architectural decisions.

### File naming

- Use the format: `[YYYY-MM-DD]-[decision-name].md`
  - Example: `2026-02-25-introduce-event-bus.md`

### How to create a new ADR

1. Copy `0001-template.md` to a new file with the correct date and decision name.
2. Fill in the **Context**, **Decision**, and **Consequences** sections.
3. Link to the ADR from relevant docs if needed (architecture, features, SOPs).
