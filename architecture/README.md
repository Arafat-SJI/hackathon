## Architecture documentation

This folder describes the overall architecture of SpecEngine: system context, application structure, infrastructure, security, and key data flows.

- `system-architecture.md` – high-level system design and main components.
- `application-architecture.md` – internal layers, modules, and boundaries.
- `infrastructure.md` – environments, hosting, CI/CD, and external services.
- `security-architecture.md` – authentication, authorization, and data protection.
- `data-flow.md` – how data moves through the system.
- `ADRs/` – Architectural Decision Records documenting important decisions.

When you make significant architectural changes, update the relevant document and, if appropriate, add an ADR.
