## SpecEngine documentation

This folder contains all project documentation for SpecEngine.

- `database/` – schema, migrations, and database rules.
- `api/` – API design, contracts, and endpoint documentation.
- `features/` – per-feature specifications and implementation notes.
- `issues/` – issue templates, known/resolved issues, and triage process.
- `SOPs/` – standard operating procedures for development, deployment, and maintenance.
- `standards/` – coding, logging, error-handling, and naming standards.
- `changelog.md` – project-level change history.

Use this directory as the entry point when you need to understand or update project behavior.
